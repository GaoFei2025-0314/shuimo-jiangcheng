# 模型精度：城市底楼与四处地标 设计

日期：2026-11-26

## 为什么做

构图一轮之后，全城、两江与近景都有了山水纵深。下一步的短板在近景：
把 16 个景点逐一拉近到默认机位的 0.42 倍距离审看（截图见本轮对话），
画面里最粗的不是主角，而是**围着主角的城市底楼**和**几处做得偏简的地标**。

- 黄鹤楼、红楼、江汉关、武大老斋舍、省博、行吟阁、楚天台、古琴台、电视塔、汉口水塔：
  近看已经耐看，本轮不动。
- 城市底楼（`apartment`、`lane`、`arcade`、`highrise`、`slab_tower`、`terrace_tower`、`wharf`）：
  黄鹤楼、长江大桥、江汉关、水塔、洪山、归元寺的近景里都占半幅画面，
  多是开着窗格的白方盒，没有檐口、屋顶设备、底层商铺或阳台，一拉近就露出「积木」感。
- 鹦鹉洲长江大桥：桥塔是两根直柱加一道横梁，读起来像脚手架；加劲梁太薄。
  它同时是「长江大桥」机位的背景主体，曝光度高。
- 归元禅寺：罗汉堂是一块带天窗的深色平板，院内只有一座殿和两座小亭，撑不起「四大丛林」。
- 洪山宝塔 · 宝通禅寺：塔身是七段直筒，没有层间腰檐；介绍里「依南坡层层而上」的寺院只有一座小殿。
- 晴川阁：楼阁本身可以，但禹功矶的岩石是几块灰色多面体，近看粗糙。

## 目标

1. 城市底楼七种屋型加上檐口、压顶、屋顶水箱或楼梯间、底层商铺雨棚、阳台或空调机位等「看得出年代与用途」的构件，
   同屋型的实例之间保留现有的体量差异。
2. 鹦鹉洲长江大桥桥塔改为有收分、上下横梁和塔顶鞍座的门式塔，加劲梁有可读的梁高与检修道。
3. 归元禅寺补齐罗汉堂的田字形屋顶与四个天井、大雄宝殿前的月台、藏经阁。
4. 洪山宝塔每层加腰檐与平座，塔顶有塔刹；宝通禅寺沿南坡中轴补到三至四进殿宇，用台阶连接。
5. 禹功矶的岩石改为有层理、有圆角的叠石，与江岸衔接。

## 非目标

- 不动上面列为「本轮不动」的十个地标。
- 不改景点位置、占地轮廓、机位、构图与界面。
- 不改水墨渲染管线与材质系统，只在现有材质槽（`cityBrick`、`cityRoof`、`cityShade` 等）上建模。

## 反目标（做到了也算失败）

- 全城与两江镜头里出现新的灰色噪点或勾线糊成一片：细部在远处必须安静。
- 帧率下降超过 10%（以 1440×900 Chromium 的现有帧率为基线，由 `perf.cjs` 同法实测）。
- 地标落地、贴地、避让江面的现有测试为迁就新模型被删除或放宽。
- 屋型改动后，街巷模式或「游两岸街巷」的近景出现穿插、悬空或朝向错误。

## 约束

- 模型只通过 `tools/blender/` 下的 Python 脚本生成，在 Blender 5.2 里经 Blender MCP 的 `execute_blender_code`
  运行 `build.py`（README「Blender 建模与渲染」一节的流程）。不手工点选建模、不导入外部模型或贴图。
- 单文件分发：`src/architecture.gen.js` 现为 5.7 MB，本轮完成后不超过 6.5 MB；
  `architecture-plates.gen.js` 随改动的地标重新渲染。
- 面数预算（场景实测，由 `scene.traverse` 统计实例化后的三角形）：
  - 现状全场景约 119 万面，其中城市底楼约 22 万面（lane 1167 栋 × 75 面，apartment 1044 栋 × 73 面，arcade 300 栋 × 91 面）。
  - 本轮完成后全场景不超过 150 万面；单栋底楼不超过现状的 3 倍。
- 地标与真实建筑的形制要对得上：改动的四处地标在提交说明里写明参考的公开资料。

## 做法比较

| 做法 | 取舍 | 结论 |
|---|---|---|
| **改 `tools/blender/` 的建模脚本，经 Blender MCP 重建** | 可复现、可审查、与代码一起提交；沿用现有导出、图录渲染与网页内嵌流程 | **采用** |
| 在 Blender 界面里手工建模，或导入外部模型 | 细节上限高，但无法从脚本重建，授权来源难查，与现有流水线断开 | 不采用 |
| 在 three.js 里程序化加细节 | 绕开 Blender，但把建筑几何拆到两套系统里，图录渲染与网页不一致 | 不采用 |

## 设计

### 1. 城市底楼（`tools/blender/neighborhood.py`）

- 每种屋型按年代与用途加构件，示例：
  - `apartment`（八九十年代住宅）：女儿墙压顶、楼梯间小屋、屋顶水箱、外挑阳台或空调板、底层入口雨棚；
  - `lane`（里分）：保留现有山墙与坡屋顶，加石库门门罩、檐口线脚、烟囱；
  - `arcade`（骑楼与洋行）：二层以上的檐口与腰线、底层骑楼柱廊进深、屋顶栏杆；
  - `highrise`、`slab_tower`、`terrace_tower`：裙楼与塔楼分段、顶部机房或收头、竖向线条；
  - `wharf`：仓房的屋架与雨棚、系缆桩。
- 构件尺寸要在近景（距离约 40–60 单位）看得出，在全城（约 1000 单位）完全并入体块：
  厚度和挑出至少 0.25 单位，不做小于 0.15 单位的线脚。
- 屋型的街面朝 -Y、原点与占地不变，保证 `04-districts.js` 的落位不受影响。

### 2. 鹦鹉洲长江大桥（`tools/blender/suspension.py`）

- 桥塔：两肢向上收分，下横梁托桥面、上横梁在塔顶下方，塔顶有主缆鞍座罩。
- 加劲梁：钢箱梁有可读的梁高与风嘴，梁侧有检修道与栏杆。
- 塔形以公开照片核对，提交说明写明来源。

### 3. 归元禅寺（`tools/blender/gardens.py` 的 `guiyuan()`）

- 罗汉堂：田字形平面，四个天井，坡屋顶（不再是平板）。
- 大雄宝殿前加月台与香炉；中轴后部加二层藏经阁。
- 院墙保留，补山门。

### 4. 洪山宝塔 · 宝通禅寺（`tools/blender/gardens.py` 的 `hongshan()`、`octagonal_tier()`）

- 宝塔：八面七级，每级之间有砖砌腰檐与平座，塔顶塔刹。
- 宝通禅寺：沿南坡中轴三至四进殿宇（山门、大雄宝殿、祖堂、方丈），每进一层台地，石阶相连；
  建筑贴合 `terrainTop`，不悬空不埋入。

### 5. 禹功矶（晴川阁）

- 岩石改为水平层理的叠石，边缘倒圆，岩脚入水；数量与范围保持在现有占地内。
- 例外：近景里的粗糙岩块可能不是 Blender 模型，而是 `src/04-planting.js` 的「低矮散石」
  或 `src/03-terrain.js` 的江岸石矶（`uQuaySpurs`）。实现者先确认来源，在原生成处修改，不为此另建一套。

### 6. 测试与验收

- 现有测试全部保留并通过（`npm test`）。
- 新增：
  - 面数预算：页面就绪后统计全场景三角形不超过 150 万；
  - 体积预算：`architecture.gen.js` 不超过 6.5 MB（放在 `tests/build.test.cjs`）。
- 截图对照（改前 / 改后，各给默认机位与拉近机位）：黄鹤楼、长江大桥、江汉关、汉口水塔、洪山、归元寺、晴川阁、鹦鹉洲大桥；
  另给全城与两江各一张，确认远处没有新噪点。
- 帧率：与改前同法实测，下降不超过 10%。

## 交给实现者决定

- 每种屋型具体加哪些构件、加多少：以近景截图为准，守住面数预算。
- 四处地标的细节层级：以公开资料与近景截图为准。
- 是否给城市底楼做按距离切换的细节层级：只有在面数或帧率超预算时才做。
