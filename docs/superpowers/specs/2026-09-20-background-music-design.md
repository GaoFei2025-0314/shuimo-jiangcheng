# 背景音乐设计

## 目标

给「水墨江城」加一段应景的背景音乐：古琴意境，疏落、留白，与水墨画面气质一致。
不引入音频文件，不增加外部资源，页面仍是单文件 HTML。

## 声音

全部用 Web Audio 现场合成。

- **琴声**：三角波 + 一倍频正弦泛音；快起慢落的拨弦包络；低通滤波器由亮扫暗；
  音头带一点下滑的音高（吟猱）；另加一声极短的指触噪声。
- **音阶**：D 调五声（宫商角徵羽），D3 至 E5 左右。
- **编曲**：随机漫步。多数走相邻音，偶跳三、四度；约两成的音同时下叠一个八度。
  每 3–6 个音成一句，句内间隔 1.1–2.4 秒，句与句之间留 5–9 秒静默。不循环，每次不同。
- **环境声**：一路棕噪声，分两支——带通的水声与低通的江风，各由极慢的 LFO 起伏。
- **空间感**：用衰减噪声生成的脉冲响应做卷积混响，琴声与环境声共用。

## 界面与行为

- 右上角一枚朱砂印章式按钮「乐」，`aria-pressed` 表示开关：关时空心朱边，开时实心朱底。
- **默认关闭**（浏览器禁止自动播放）。`AudioContext` 在第一次点击时才创建。
- 开：主音量约 2 秒淡入。关：约 1 秒淡出，随后 `suspend`。
- 标签页隐藏时暂停，回来后继续。
- 不支持 Web Audio 时隐藏按钮，其余功能不受影响。
- 不记忆开关状态：记住了也无法在下次打开时自动出声。

## 验证

- `node --check`（构建脚本已含）。
- 浏览器内点击按钮，用 `AnalyserNode` 读输出电平：开启后非零，关闭后归零；控制台无报错。
- 音色好坏靠人耳，交由用户试听后再调。
