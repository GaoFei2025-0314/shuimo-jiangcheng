# 构图：压低视角、远山与墨晕入场 设计

日期：2026-11-26

## 为什么做

画风与界面两轮之后，整体审美约 8.5 分。离 9 分以上还差的主要是构图：
全城与入场镜头俯角大（26°–30°），整张画只有「中景城市」一层，上方是空纸，
近、中、远没有递进；三镇的小方块平均撒开，眼睛没有落点。

用户选定方向：**压低视角，让远山进入画面**。远山的做法选定为：
**最远两三层用画布绘制的水墨剪影，近处山岭仍用三维模型并加大。**

## 现状（实测）

- `src/03-terrain.js` 已有四层远岭（汉口北 z=-980、-1360，武昌南 z=+1080、+1520），
  高 48–76 单位。俯角 26° 时在画框外；压到 11°–16° 时只是地平线上一道看不出的细边。
- `src/05-runtime.js` 的 `fitSunToSky` 已经按地平线在画面中的高度（`horizonY`）
  算出 `--sky-fit`，地平线入画时显示朱砂日（`#sun`）和江天云气（`#river-sky`，位于画布之后）。
  WebGL 画布是透明底，画布后面的层可见。
- 只压低俯角、保持距离（试拍见本轮对话）：太阳出现，但城市压成画面中部一条窄带，上半幅空天。
- 镜头：`VIEWS` 用 `orbit(at, y, dist, az, el)` 定义；多数景点再经 `fittedView` 按界面留出的
  安全区自动取距离。竖屏有单独的 `home`、`core`、`tower`、`lake`、`bridge` 机位。
- 入场：`#stage` 用 CSS `inkFade`（1.5s 透明度渐显）。

## 目标

1. 全城与入场（两江）镜头压低到能看见地平线，城市仍占满中景、读得出三镇与两江。竖屏全城按下文修订，以读图为先。
2. 地平线上有三层水墨远山：浓淡递减、山脚入云、留出天空。转动视角时远山随方位平移，
   各层速度不同，形成视差。
3. 城外近岭（现有三维远岭）加高加大，成为远山与城市之间的过渡层。
4. 逐一复核 17 个景点机位，让背景是天空的景点也带上远山。
5. 入场改为「墨晕」：画面从中心向外洇开，而不是整体渐显。

## 非目标

- 不改地理数据、不改建筑模型、不改界面控件。
- 不做昼夜与天气变化。
- 不重绘 `#river-sky` 云气图。

## 反目标（做到了也算失败）

- 地图读不出来：全城镜头里看不清两江交汇、三镇分区或东湖轮廓。
- 远山与景点牌签、地名题记重叠，或盖住朱砂日。
- 帧率明显下降（以现有 1440×900 Chromium 约 33 fps 为基线，下降不超过 10%）。
- 现有「主体落在安全区内」「太阳只在地平线以上」等回归测试为迁就新构图而被删除或放宽。
  可以随新机位更新期望值，但约束本身保留。

## 约束

- 单文件分发：远山不能是外部图片，在运行时用 2D 画布程序生成（与 `printPlate` 同类做法），
  或由 `tools/` 离线生成后内嵌。
- 减少动态效果时：墨晕入场直接显示终态，远山不做平移动画。
- 手机竖屏视野窄，远山与地平线要按竖屏另行取位。
- 街巷模式（`streetView`）已有自己的天色与太阳处理，远山在街巷模式淡出，不干扰。

## 做法比较

| 做法 | 取舍 | 结论 |
|---|---|---|
| **画布远山 + 三维近岭** | 远山的墨色、留白、山脚云气可以像画一样控制；几乎零渲染开销；不碰深度勾线与地形测试。最远层没有真实视差，大角度绕城时略显贴在后面 | **用户选定** |
| 全用三维山 | 任何角度都真实；但要拉远远裁面、重调雾和深度精度，远山在雾里容易成灰土包，还会挡住天色与太阳 | 未选 |
| 只靠墨色加强层次、保持俯瞰 | 地图最准确、改动最小，但仍是「地图」，没有山水纵深 | 上一轮已否决 |

## 设计

### 1. 画布远山层 `#far-hills`

- 新元素放在 `#river-sky` 与 `#stage` 之间（z 序：云气 < 远山 < 画布），`pointer-events: none`、`aria-hidden`。
- 启动时用 2D 画布生成三条横向可平铺的山脊带（每条宽约 2400px、高约 260px），转成 blob URL：
  - 山脊线：多频噪声叠加，远层平缓、近层起伏大；
  - 墨色：远层最淡（接近纸色），近层稍浓；每层顶部有干笔边、向下渐隐到纸色（山脚入云）；
  - 纸纹与现有 `#grain` 一致，不另加。
- 每层作为一个背景层：
  - 垂直位置：底边贴在 `horizonY` 附近（各层略有错落），随镜头俯仰上下移动；
  - 水平位置：按 `controls.getAzimuthalAngle()` 平移，三层系数不同（远慢近快）；
  - 显隐：复用 `--sky-fit`，地平线出画时淡出；街巷模式淡出。
- 每条山脊带的下半部是不透明的纸色云气（向下一直铺到层底）。WebGL 画布在地面边缘与地平线之间
  是透明的（地面只延伸到城区外 450 单位），这条空隙由远山的山脚云气补上。
- **朱砂日**（作者决定）：层级上仍在远山之后（DOM 顺序：`#river-sky`、`#sun`、`#far-hills`、`#stage`），
  位置上由 `fitSunToSky` 把太阳圆盘的下沿限制在最高一层山脊线之上，最多允许下沿被山脊掩住 15%，
  形成「日出山间」，但不被遮住。测试量的是太阳包围盒的下沿与该处山脊线的高度。

### 2. 三维近岭

- 现有四层远岭整体加高（约 2.5–3 倍）并加宽，必要时在东西两侧各补一层，形成环抱。
- 继续用 `riverClearance` 让开江面；墨色比城市淡、比画布远山浓，作为中间层。
- 衔接方式（作者决定）：画布远山在三维画面之后，三维近岭会盖住远山的山脚，所以衔接靠三维一侧：
  近岭顶部随雾淡到纸色，远山层的底边上提到近岭山脊附近，二者在云气里接上。
- 加高哪几层（作者决定）：全城镜头从南往北看，画面里只有汉口北的两层（z=-980、-1360），优先加高这两层；
  武昌南的两层在环绕时才入画，同比例加高；东西两侧是否补层看环绕截图再定。全城镜头方位角不变。

### 3. 机位

- **全城**：俯角从 26° 降到约 15°–17°，同时拉近，让城市横向占满安全区；
  地平线落在画面上方约 25%–32% 处，留给远山和天空。这是取景目标，不是硬指标；
  测试只约束地平线落在画面上方 15%–40% 之间（作者决定）。
- **两江（入场）**：俯角从 30° 降到约 17°–19°，龟蛇两山与大桥仍在画面中心偏下。
- **其余景点**：逐个复核，原则是：
  - 背景为天空或江面的景点（黄鹤楼、晴川阁、长江大桥、鹦鹉洲大桥、电视塔、江汉关）：可略降俯角，让远山出现在建筑之后；
  - 以平面布局为主的景点（东湖、武大、省博、归元寺）：保持现状，以看清布局为先。
- **竖屏（作者决定，经截图复核修订）**：宽小于高时，全城以读图为先。在窄画幅里以低俯角横收三镇，需要把相机退得很远，两江交汇与东湖便在雾中挤成一条窄带。
  全城沿用原方位角 49°，俯角取 38°，视野角至多 60°。取景范围由三镇建成区的建筑落点与完整东湖岸线确定，地形底板四角可以出画。
  在 390×844 和 360×640 上，建成区与湖岸全部位于安全区内，合计纵向跨度至少占安全区高度的 45%，横向至少占视口宽度的 70%，东湖岸线的投影宽度至少为 120px。
  地平线可以出画，太阳与画布远山随之淡出。
  竖屏两江沿用现有低俯角入场机位，保留地平线和远山。
- 牌签与远山（作者决定）：允许竖牌和题记压在远山上。竖牌有纸色底、题记有纸色描边，可读性不受影响，
  所以不做重叠检测，也不为此调整机位；只在截图检查里确认对比度。

### 4. 墨晕入场

- `#stage` 的入场从整体渐显改为遮罩洇开：
  - 遮罩是一个从中心向外扩散的不规则墨晕，边缘带纤维噪声；
  - 用 CSS `mask-image`（SVG 噪声 + 径向渐变），配合一个自定义属性做 1.6–2s 动画。
- 远山层同步淡入，比画布稍早，营造「先有远山、后有城市」的观感。
- 就绪（`window.__ready`）不等动画结束；减少动态效果时直接显示终态。

### 5. 测试

- 新增：
  - 两江及横屏全城镜头下地平线位于画面上部、远山层可见；竖屏全城按上述读图要求验收；
  - 俯视镜头下远山层隐藏；
  - 远山不遮住朱砂日。
- 更新：「入场以核心城区开场」「主体落在安全区」等测试随新机位更新期望值，约束保留。

## 交给实现者决定

- 远山噪声参数、各层墨色与错落高度、视差系数：以截图为准调整。
- 各景点降多少俯角：以截图为准，满足上面的原则即可。
- 近岭补不补东西两侧：看全城镜头是否需要环抱感。
