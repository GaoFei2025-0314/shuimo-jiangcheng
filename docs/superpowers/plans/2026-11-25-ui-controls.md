# 界面控件水墨化 实施计划

> **给执行者：** 配合 superpowers:executing-plans 逐任务执行，步骤用 `- [ ]` 勾选。
> 每个任务做完都要截图对照（桌面 1440×900、手机 390×844），并跑 `npm test`。

**目标：** 画面已统一为水墨印刷，叠在上面的控件仍是网页默认样式：细边框方按钮、系统下拉框、
浏览器蓝色焦点环、三行平铺的导航。本计划把它们收进同一套纸、墨、朱砂的视觉语言，
把整体审美从约 7.5 分推到 8.5 分左右。

**原则：**

1. **只有三种材料：** 宣纸（`--paper`）、墨（`--ink` 各级灰）、朱砂（`--cinnabar`）。不新增颜色。
   现有的 `#854837`、`#824931`、`#774733`、`#a85540` 等棕红色合并成一个 `--cinnabar-deep`。
2. **控件不画框：** 按钮靠字、下划墨痕、印章三种形态区分，不再用 1px 方框。
3. **两种字体：** 书法体只用于题名、地名、竖牌和景点标题；其余 UI 统一用宋体（`--song`）。
4. **不破坏既有行为：** 保留所有 `id`、`aria-*` 属性和原生 `<select>` 元素（只改外观），
   让 142 项浏览器回归测试和键盘访问继续成立。

**改动范围：** 只动 `src/00-shell.html`（CSS 与少量结构）和 `src/05-runtime.js`、`src/05-layout.js` 中
与控件相关的几行。不动渲染。
