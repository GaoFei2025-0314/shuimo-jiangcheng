# 树与屋型去重复 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 屋型与树都改为 Blender 建模的多变体，按位置挑选，消除近景的阵列感。

**Architecture:** `tools/blender/neighborhood.py` 增加屋型变体，`tools/blender/trees.py` 新建树种变体（三级细节与着色属性），`build.py` 编码；`src/04-scene.js` 与 `src/04-planting.js` 按位置哈希选变体。

**Tech Stack:** Blender 5.2（经 Blender MCP 127.0.0.1:9876 运行 `runpy.run_path("<项目绝对路径>/tools/blender/build.py", run_name="__main__")`）、three.js r128、Playwright（Chromium + WebKit）、node:test。

**Spec:** `docs/superpowers/specs/2026-11-27-variety-design.md`

## Global Constraints

- 全场三角面 ≤ 1,500,000；每个屋型变体 ≤ 所属屋型基线 3 倍；`dist/index.html` ≤ 12 MB。
- 帧率（1440×900 Chromium，`node /private/tmp/claude-501/-Users-gf--claude-spares-spare-tnKzZb/b1a8738f-204e-421a-924d-cd1342d2bd17/scratchpad/perf.cjs "$PWD" 8765`，改前改后各两次）下降 ≤ 5%。
- 不改摆放位置与数量、机位、界面、地标；不删不放宽测试；临时文件放 `/tmp/shuimo-variety/`；不推送。

## Review Focus

1. 树搬进 Blender 后风动、三级细节切换、纸花小枝、阴影（`src/04-planting.js` 阴影目标）与淡化仍正常。
2. 依赖 `City / <kind>` 名称的代码与测试（`src/05-runtime.js`、`far-hills`、`visual-study`）在新增变体后含义不变。
3. 相邻变体真的不同：哈希规则在密集街区（汉口里分、昙华林）仍避开同变体相邻。
4. 竖屏与减少动态效果下画面正常。
5. 远景（home、core）城市肌理与树林浓度基本不变。
